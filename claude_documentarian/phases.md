# Documentarian Phases

The Documentarian's work is organized into phases. Each session advances the current phase. Phase changes require a special phase-change session that consults the Human and creates a per-phase plan.

This file tracks ONLY the phase outline and current status. Per-phase plan files live in `claude_documentarian/plans/` and are created at phase entry. Do NOT add session-level history, drift annotations, or transition notes here. Per-phase plan files in `claude_documentarian/plans/phase_<N>_*.md` follow the same discipline: only Scope / Phase guidelines / Exit criteria / Agent needs sections survive between sessions; do NOT add session-level history, drift annotations, or transition notes to those files either. Per-session content lives in the journal Next Session Plan.
